# 📊 Loan Default Prediction Using Logistic Regression in R

## 📘 Project Overview
This R project builds a **logistic regression model** to predict whether a borrower will default on a loan based on features like **age**, **income**, **loan amount**, and **credit score**. It uses statistical modeling and data visualization techniques to evaluate the prediction accuracy.

---

## 🎯 Objectives
- Clean and explore borrower data.
- Visualize the relationship between features and loan default.
- Build a logistic regression model using `glm()` (binomial family).
- Predict probabilities and classify defaults using a threshold.
- Evaluate model using:
  - Confusion Matrix
  - ROC Curve
  - AUC Score

---

## 🛠️ Technologies & Libraries
- **R programming language**
- **Libraries used:**
  - `dplyr` – data manipulation
  - `ggplot2` – data visualization
  - `caret` – evaluation metrics
  - `pROC` – ROC and AUC calculations
  - `caTools` – splitting dataset
